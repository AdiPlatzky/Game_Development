# הברקה — ארבע חידות תלת־ממדיות: חבילת פיתוח

**התחל כאן:** `docs/levels-00-03.md` מכיל את מפרט P00-P03, כולל חפצים, מיקומים במטרים, כל לחיצה/גרירה/סיבוב, תגובות, תנאי הצלחה, רמזים, תזמון, מסכי תוצאה ובדיקות קבלה.

- `diagrams/all-four-levels.png` — תצוגה מהירה של ארבע מפות החדרים.
- `diagrams/P00-kitchen.png` עד `P03-clocktower.png` — מפות מבט־על מפורטות עם מפתחות אובייקטים.
- `data/puzzle-data.json` — JSON תיאורי לצוות המימוש (לא סקריפט Unity עובד).
- `data/build_diagrams.py` — קוד המקור ליצירת המפות הטכניות.

זו **חבילת תכנון בלבד**: לא נבנו עדיין סצנות ב־Unity, המיקומים הם הצעה לפני בדיקת תלת־ממד בפועל, והזמן/רמות הקושי הם יעדי ניסוי ולא מדידות.

**סדר הרמות:** P00 Tutorial (מטבח) → P01 קל (מלונה) → P02 בינוני (סדנה) → P03 קשה (מגדל השעונים).
